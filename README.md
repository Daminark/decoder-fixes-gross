Comparing decoder fixes for sub-distance failures on the gross code.

## Status, 15 November 2026

**The question.**
Iterative decoders of the circuit-level \[[144,12,12]\] gross code fail on some fault sets of weight 4, far below the circuit distance, and several fixes have been proposed, each tested against its own baseline.
This project scores them on one yardstick: the published trapping-set supports of Pacenti, Raveendran and Vasić (arXiv:2608.11516, Zenodo record 21878685) and Landa's weight-4 fault list (arXiv:2603.19126), decoded exhaustively, with the code's 72 translations making the exhaustive pass cheap.
The result to aim for is one table with a row per decoder: the failing sets by weight, the error floor those failures predict, and the decode cost.

**Reproduced so far.**

- The Relay-BP result of the trapping-set paper: 143,350 failing trapping sets against the paper's 152,857, in the same five classes of trapping sets, with no failure below weight 4 ([the reproduction](docs/explanation/reproduction.md)).
- The orbit reduction of the Zenodo lists: 92,088,579 published rows reduce to 1,279,071 representatives under the translation group Z_12 × Z_6, which the canonical-labelling tool Bliss confirms is the full automorphism group of the detector error model ([the model and its symmetry](docs/explanation/model-and-symmetry.md), [the failure lists](docs/explanation/failure-lists.md)).

**Running.**
The other decoders of the comparison (Relay-BP with other settings, BP+OSD, BP+LSD, and Landa's augmentation under each) through the same exhaustive pass, toward a first table on 2 December 2026.

**Planned.**
Results frozen on 12 December 2026; write-up on 19 December 2026.

**A note on the dataset.**
Ten of the Zenodo CSV files end before their last orbit is complete, 1,473 rows of 92 million in all, and eight end in a line without a newline.
Counts compared with the paper are taken on the rows as published, and the missing rows are restored by orbit closure; [the failure lists](docs/explanation/failure-lists.md) states the exact effect of each.

## Usage

Load the model, build the baseline decoder, and decode one injected fault set:

```python
from decoder_fixes_gross.dem import dem_at
from decoder_fixes_gross.decoders import RelayBP
from decoder_fixes_gross.inject import decode_injected

dem = dem_at(1e-3)  # the detector error model at physical error rate 1e-3
decoder = RelayBP(dem, seed=1)  # Relay-BP with the baseline settings
decode_injected(dem, decoder, [0, 1, 2, 3])  # inject four faults, decode, classify the outcome
```

The full reproduction needs the Zenodo dataset and about an hour of compute; [reproducing the figures](docs/howto/reproduce-figures.md) lists the commands in order.

## Relation to similar work

The trapping-set paper (Pacenti, Raveendran and Vasić, arXiv:2608.11516) enumerates the failure structures and scores Relay-BP, ImpulseBP and ELMS on them; this project reproduces its Relay-BP result and extends the scoring to the proposed fixes.
Landa (arXiv:2603.19126) lists the weight-4 faults of the syndrome-extraction circuit and proposes augmenting the decoding model with them.
The decoders come from the `relay-bp` package (Müller et al., arXiv:2506.01779) and the `ldpc` package (BP+OSD and BP+LSD, with the settings of arXiv:2511.15177).
The circuit is generated by the code of Gong, Cammerer and Renes (arXiv:2403.18901); see `third_party/` for licences and attribution.
