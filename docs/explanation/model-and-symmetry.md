# The model and its symmetry

Every result in this project is a statement about one detector error model, and every exhaustive test is made affordable by its symmetry.
We first describe the circuit and the model derived from it, then how the model changes with the physical error rate.
We then turn to the 72 translations of the code, the orbits they cut the fault sets into, and why one decode per orbit suffices for any decoder once the decoded member of the orbit is chosen at random.

## The circuit and its detector error model

The code is the \[[144,12,12]\] bivariate bicycle code of Bravyi et al. (Nature 627, 778, 2024), with l = 12 and m = 6, whose checks sit on a 12 x 6 torus.
The circuit is the syndrome-extraction circuit of Gong, Cammerer and Renes (arXiv:2403.18901), generated by their `build_circuit` for a Z-basis memory experiment with 12 rounds.
Every noise channel in it (reset and measurement flips, single- and two-qubit depolarization) has probability equal to the physical error rate p, and the stored circuit has p = 1e-3.
It defines 936 detectors, the 72 Z checks in each of 13 layers, and 12 logical observables.

Stim turns the circuit into a detector error model: a list of independent fault mechanisms, each with the detectors and observables it flips and its probability.
At p = 1e-3 the flattened model has 10,368 error instructions, and some of them flip the same detectors and observables.
We merge each such group into one column whose prior is the sum of the probabilities, which is the rule of `dem_to_check_matrices` in Gong et al.'s code.
The exact probability that an odd number of the merged mechanisms fire differs from the sum at second order, a relative difference of order 1e-3 at these rates; we follow the sum so that the priors agree with those of the model the published trapping-set lists were computed on.
The result is 8,784 columns, in order of first appearance in the flattened model.
This order matters: the trapping-set supports of Pacenti, Raveendran and Vasić (arXiv:2608.11516) are lists of column indices in exactly this order.

The model is then three objects:

- the check matrix `h`, 936 x 8,784 over GF(2), of rank 930;
- the observable matrix `l`, 12 x 8,784;
- the priors, one probability per column.

Every column has a distinct detector pattern, so a column is determined by the detectors it flips.

## The model at other error rates

The estimate of the failure floor weights each fault set by its probability at p between 1e-4 and 1e-3, and the Monte Carlo check samples at rates above 1e-3.
A model stored at 1e-3 alone does not give these probabilities exactly, because the probability Stim assigns to a mechanism can combine several circuit faults and is not exactly proportional to p.
Since every noise argument in the circuit equals p, we instead rebuild the circuit at p by multiplying each noise argument by p / 1e-3, and derive the model from it.
Which mechanisms exist does not depend on p, so `h`, `l` and the column order are the same at every rate, and only the priors change.
At p = 1e-4 every prior is between 0.095 and 0.105 times its value at 1e-3, which is the size of the departure from proportionality.

## The translations

Write detector `72 * layer + 6 * a + b` for the check at position (a, b) of the torus in a given layer, with a in 0..11 and b in 0..5.
The group element g = 6 s + u, with s in 0..11 and u in 0..5, translates (a, b) to ((a + s) mod 12, (b + u) mod 6) in every layer.
The code is invariant under these translations, and the circuit schedules every check in the same way, so a translation maps each fault mechanism to another mechanism of the same kind.
Concretely, the image of the detector set of every column is again the detector set of a column, so each translation acts on the 8,784 columns as a permutation.

Each of the 72 permutations preserves `h` up to the matching permutation of detectors, and preserves the priors exactly.
The observables are another matter.
The 12 rows of `l` are one choice of logical representatives, and that choice is not translation invariant.
What holds instead is that the translated rows are an equivalent choice: they lie in the row space of `h` and `l` together, and they are still independent modulo `h`, so that the rank of `h` stacked on the translated `l` is again 942.
This is what decoding needs.
A decode leaves a residual (the fault plus the correction), and when the residual has zero syndrome, the decode fails exactly when some observable flips.
On a residual with zero syndrome, the translated observables are an invertible recombination of the original ones, so one set flips exactly when the other does.

## Orbits and canonical forms

The translations act on fault sets, i.e. sets of columns, and split them into orbits.
Each single column has 72 distinct images, so the 8,784 columns form 122 orbits of size 72.
A larger set can be fixed by some translations, and its orbit is then smaller: by the orbit-stabilizer theorem the orbit size is 72 divided by the number of translations that fix the set.
For instance, g = (6, 0) has order 2, so for any column c the pair {c, g c} is fixed by g and has an orbit of size 36.

To store one representative per orbit we need a rule that picks the same member from every set in the orbit.
We take the canonical form of a set to be the lexicographically smallest of its 72 images, each written as a sorted list of column indices.
Two sets have the same canonical form exactly when they lie in the same orbit, so canonicalizing and deduplicating a list of sets reduces it to its orbits.

## Why one decode per orbit is enough

Translating a fault set S by g translates everything a decoder is given.
The syndrome of g S is the syndrome of S with its detectors relabelled, every column keeps its prior, and by the previous section a residual with zero syndrome flips an observable exactly when its translate does.
Every set in an orbit therefore poses the same decoding problem, up to a relabelling of detectors and columns, and every set in it has the same probability.
The failure mass of an orbit is its size times that probability times the fraction of its sets on which the decoder fails, and only this fraction depends on the decoder.

One decode per orbit estimates the fraction.
Decoding one uniformly random translate gives a failure indicator whose expectation is exactly the fraction, for any decoder; the estimator built on this, and its error, are the subject of [ADR 0003](../adr/0003-estimate-the-floor-from-one-translate-per-orbit.md).
Call a decoder equivariant when translating the syndrome translates the correction.
For an equivariant decoder the fraction is 0 or 1, since the residual of g S is the translate of the residual of S, and the single decode gives it exactly.

Nothing in this argument uses the fact that the translations are all the symmetries of the model.
Orbit reduction is valid for any group of symmetries, and a larger group would only merge orbits and shorten the lists.
For the record, the automorphism group of the Tanner graph of `h`, with columns coloured by their prior, has order exactly 72, as computed with the canonical-labelling tool Bliss of Junttila and Kaski (ALENEX 2007), so the translations are all of it.

## Decoders that are not equivariant

Several of the decoders compared here are not equivariant.
A decoder breaks ties by column index, as ordered-statistics post-processing does when it sorts columns by reliability; another draws random numbers, as Relay-BP does for its memory strengths.
For such decoders, translates of the same fault set can decode differently, and the fraction of an orbit that fails can lie strictly between 0 and 1.

This is why the decoded member is a random translate and not the canonical representative.
The canonical representative is chosen by column index, which is exactly what such a decoder can be sensitive to, so its outcome is a fixed and possibly unrepresentative member of the orbit.
A random translate removes that dependence at the cost of sampling error, which ADR 0003 bounds.
